# roof — эволюция крыши-брахистохроны

Учебный проект: генетический алгоритм ищет форму ската, с которой капля скатывается быстрее всего (брахистохрона → циклоида).
Тот же алгоритм, что в `../teo-leg` и `../watch`: турнир из трёх, худший умирает, потомок с одной мутацией. Видов нет:
задача гладкая, хватает простой схемы.

**Главная цель — понятность для обучения.** Каждая часть системы — отдельный файл с комментариями.

## Запуск и проверка

- Браузер: открыть `index.html` (работает с `file://`, без сервера и интернета).
- Без браузера: `node tools/headless.js [поколений] [пул] [seed] [drop|rain] [W] [H] [кусков] [floor]` — те же `js/*.js` через `vm`
  (~145 тыс. спариваний/с для одной капли, ~45 тыс./с для дождя).
- Эталоны (1000 поколений, пул 500, W 4, H 3, 16 кусков):
  - `drop`, seed 1–6 — все **1,1563 с**, оценка 2,1272 (циклоида из 16 кусков 1,1588, гладкая 1,1359, прямая 1,3034, дуга 1,1578).
    К 300-му поколению seed 1 ещё в «желобе» (1,2245), остальные 1,157–1,172;
  - `rain`, seed 1: **0,8899 с**, оценка 2,0177 (прямая 0,9057, дуга 1,0917, циклоида 0,9883);
  - `drop 8 2 16`: 1,7848 с (циклоида 1,7966, уходит ниже карниза); с `floor`: 1,8601 с (циклоида до карниза + полка 1,8873).
  Если цифры изменились, значит, поменялась модель, оценка или последовательность вызовов rng.
- Скриншот без браузера: headless Chrome с `--screenshot` по `file://`. Чтобы снять страницу после эволюции, временная копия
  `index.html` в scratchpad с абсолютными путями к `js/` и скриптом, который жмёт `btn-gen` (нужен `--allow-file-access-from-files`).

## Архитектура

Обычные `<script>` в фиксированном порядке, глобальные функции. Без модулей и зависимостей (ради `file://`).

| Файл | Роль |
|---|---|
| `js/rng.js` | Генератор с seed (копия из `teo-leg`) |
| `js/roof.js` | `G`, `TASK` (width, height, segments, rain, floor), `roofPoints`, `randomRoof`, `crossover` (один разрез), `mutate`; эталоны `linePoints`, `arcPoints`, `cycloidShape`/`cycloidPoints` |
| `js/fitness.js` | `slide` (одна капля, точное время по кускам), `measure` (капля или дождь), `setTask` (задача + эталоны `REFS`), `classify`, `evaluateRoof`, `roofStats` |
| `js/evolution.js` | Класс `Evolution`: турнир из трёх, история `{counts, best, time}`, `stopReason` (близость к циклоиде — только для одной капли) |
| `js/draw.js` | Дом в разрезе, гонка капель (`dropPosition` — точное положение при постоянном ускорении на куске), график пула со временем лучшей и эталонов |
| `js/app.js` | UI: кнопки, цикл `requestAnimationFrame`, панели |

## Логика модели

- Половина разреза: конёк (0, H), карниз (W, 0). Ломаная из N кусков равной ширины, геном — N − 1 высот. Диапазон высот:
  [−H, H], с `floor` — [0, H].
- Капля без трения: на куске v₂ = √(v₁² + 2g(y₁ − y₂)), время = длина / ((v₁ + v₂)/2). На изломе неупругий удар:
  v → v·max(0, cos поворота). Скорость кончилась на подъёме → застревает. `slide` отдаёт `speeds` (скорость в начале
  каждого куска после поворота) — по ним `dropPosition` в draw.js рисует движение.
- Застрявшая капля: доля = `stopX` / W, где `stopX` учитывает, насколько капля заехала вверх по стенке ямы (v²/(2g·sin)).
- Дождь: старт без скорости с конька и с каждого излома (кроме карниза), T — среднее. Застревает хоть одна → оценка = доля дошедших.
- Оценка: застревает → доля (0..1); иначе 1 + T_прямой / T.
- Классы: застревает / медленнее прямой / быстрее прямой / быстрее дуги / не медленнее циклоиды больше чем на 1 % (`NEAR_CYCLOID`).
- Эталоны меряются как ломаные из тех же N кусков (`REF_DETAIL = 1`), рисуются гладкими. Гладкая циклоида — `cycloidShape().exactTime`.
- Дуга Галилея — окружность через конёк и карниз с центром над карнизом (к карнизу подходит горизонтально).
- Циклоида: (T − sin T)/(1 − cos T) = W/H, бисекция. При W/H > π/2 уходит ниже карниза; с `floor` — полуарка 2R = H и полка.

## Важные решения и грабли

- **Эталоны из тех же кусков.** Сначала эталоны мерились в 20 раз мельче, и эволюция упиралась в +0,46 % от циклоиды
  и формально не обгоняла даже дугу: ломаная с равными по ширине кусками не может дать вертикальное начало у конька.
  Теперь сравнение честное, а гладкая циклоида показана отдельно как предел.
- **Капля «без гравитации» (замечание пользователя).** Сначала скорость на изломе сохранялась целиком (только энергия):
  капля в V-образной яме отражалась и взлетала по крутой стенке почти до высоты старта. Закрыто неупругим ударом на изломе.
- **Ступенчатая оценка застрявших.** После удара на изломе все крыши застревали на 94 %: яма у карниза, а доля считалась
  по пройденным узлам — подъём дна ямы не менял оценку, эволюции не за что было зацепиться. Закрыто: учитывается, насколько
  капля заехала вверх по стенке.
- Из-за ударов лучшая 16-кусковая ломаная (1,1563) быстрее и вписанной циклоиды (1,1588), и дуги (1,1578): у конька циклоида
  резко поворачивает, и выгоднее положе. До гладкой циклоиды 1,8 %. Сходимость медленнее, чем без ударов (~600 поколений против ~60).
- В дожде циклоида проигрывает даже прямой: у карниза она пологая, капли там стартуют с места. Оптимум почти прямой.
  Поэтому автостоп «близко к циклоиде» в дожде не работает.
- Все seed сходятся к одной крыше (задача гладкая, один оптимум) — в отличие от `teo-leg`, где разброс огромный.

## Идеи на перспективу

- Трение (кулоново или вязкое, как у плёнки воды): ответ сместится от циклоиды.
- Неравные куски: x точек излома тоже в геноме — тогда ломаная повторит вертикальное начало циклоиды.
- Таутохрона: на циклоиде капли с любой высоты приходят в нижнюю точку одновременно — показать гонкой капель.
- Стоимость кровли (длина ската) как доп. правило.
