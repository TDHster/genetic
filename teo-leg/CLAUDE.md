# teo-leg — эволюция ноги Тео Янсена (Strandbeest)

Учебный проект: генетический алгоритм проектирует шагающую ногу на кривошипе. Главный критерий — скорость ходьбы. Два режима:
- **свободный** (по умолчанию): эволюция с нуля выбирает всё — число шарниров, что к чему крепится, длины, точки рамы, стопу;
- **схема Янсена**: топология его, меняются только длины и точка рамы B — как делал сам Янсен в 1990-х.
Брат-близнец проекта `../watch` (эволюция часов): тот же алгоритм, другая «модель мира» и оценка.

**Главная цель — понятность для обучения.** Каждая часть системы — отдельный файл с комментариями.

## Запуск и проверка

- Браузер: открыть `index.html` (работает с `file://`, без сервера и интернета).
- Без браузера: `node tools/headless.js [поколений] [пул] [seed] [free|jansen]` — те же `js/*.js` через `vm`.
- Доп. правила задаются переменной окружения: `FIT=height,angle,compact` (веса 0..1, по умолчанию `0.05,0.05,0.05`;
  на странице по умолчанию тоже по 5 % — решение пользователя). Янсен при 5 % — **76,02**.
  Эталоны ниже без «доп. правил» — сняты до их появления; для повтора запускать с `FIT=0,0,0`.
- С `FIT=0.5,0.5,0.2`: Янсен **34,96**; `free species` seed 1–6: 56,2 / 23,6 / 58,4 / 30,0 / 64,3 / 75,2.
- Эталоны (500 поколений, пул 500), `FIT=0,0,0 node tools/headless.js 500 500 <seed> <mode> <species|plain>`:
  - нога Янсена получает **81,57**: скорость 131,4 см/оборот, опора 1, ровность 0,870, просвет 9,6 см → 0,961, подъём 22,5 см → 0,734, материал 479 см; 7 звеньев;
  - `free species`, seed 1–6: 92,7 (7зв) / 32,0 (3) / 80,4 (11) / 28,9 (3) / 79,3 (7) / 87,1 (3);
  - `free plain`, seed 1–6: 28,0 / 31,3 / 27,8 / 62,8 / 54,0 / 42,8 (почти все 3 звена);
  - `jansen`, seed 1–6: 59,8 / 63,9 / 71,5 / 62,7 / 22,1 / 64,1.
  Если цифры сильно изменились, значит, поменялась модель, оценка или последовательность вызовов rng.

## Архитектура

Обычные `<script>` в фиксированном порядке, глобальные функции. Без модулей и зависимостей (ради `file://`).

| Файл | Роль |
|---|---|
| `js/rng.js` | Генератор с seed (копия из `watch`) |
| `js/linkage.js` | Геном (рама + список шарниров + стопа), `usedPoints`, `rigidBodies` (звенья), `barMaterial`, `randomLeg`, `crossover`, `mutate`; кинематика: `circleIntersection`, `legPose`, `simulateLeg`; эталон `JANSEN` |
| `js/fitness.js` | `measureGait` (путь стопы → опора и перенос, шаг, скорость, ровность, просвет над шагом, подъём, нарушения), `evaluateLeg` (класс и оценка), `JANSEN_SCORE` |
| `js/evolution.js` | Класс `Evolution`: турнир из трёх, виды с квотами (`updateQuotas`, `stepWithSpecies`, `speciesTable`), история `{counts, best}`, `stopReason` |
| `js/draw.js` | Анимация ноги, путь стопы (+ путь Янсена, совмещённый по земле), график пула с линией лучшей оценки, `drawWalker` — зверь в косом 3D: 2 коленвала (перед/зад) по LEGS/2 ноги, фазы спереди 0/120/240°, сзади 60/180/300° |
| `js/app.js` | UI: кнопки, цикл `requestAnimationFrame`, панели оценки и длин, импорт и экспорт JSON |

## Логика модели

**Точки** (y вверх, см): 0 O — ось кривошипа (0,0); 1 M — конец кривошипа (радиус 15, фиксирован — задаёт масштаб);
2 B и 3 B2 — точки рамы (координаты в геноме, диапазон [−80, 80]); 4+ — шарниры C, D, E… (до 10).

**Шарнир** = `{a, b, ra, rb, side}`: висит на двух *более ранних* точках a и b на расстояниях ra и rb (диапазон [5, 100]).
Положение — пересечение двух окружностей, `side` выбирает одно из двух решений. Ссылки только назад,
поэтому нога считается шаг за шагом и любой геном корректен. Не пересекаются — нога разваливается.
Ограничение: механизмы, где несколько шарниров надо решать совместно (группы Ассура выше II класса), так не строятся.

**Стопа** — номер одного шарнира (−1, если шарниров нет). `usedPoints` — стопа и всё, от чего она зависит.
Остальные шарниры нейтральны: не влияют на «разваливается», не считаются в материал, рисуются бледно.

Нога Янсена в этой записи — 5 шарниров: C(M,B) D(M,B) E(B,C) F(E,D) G(F,D), стороны −1, +1, +1, −1, −1; B = (−38, −7.8).

**Скрещивание**: число шарниров от случайного родителя, каждый шарнир от случайного родителя, у которого он есть.
Точки рамы и стопа тоже от случайного родителя. Корректность гарантирована ссылками назад.

**Стартовый пул** (free): цепочка из 1–5 шарниров, каждый висит на предыдущем и на случайной более ранней точке, стопа — последний.
Раньше стопа выбиралась случайно, и ~90 % стартовых ног были одношарнирными.

**Мутации** (одна на потомка). Свободный режим: длина 35 %, точка рамы 10 %, переворот 10 %, перецепка 15 %,
новый (нейтральный) шарнир 10 % (в конец), удаление шарнира 10 % (ссылки сдвигаются, ссылки на удалённый переносятся случайно),
смена стопы 10 %. Режим Янсена: длина 85 %, точка B 15 %. Длина: 80 % — сдвиг на 0,1..10 % диапазона, 20 % — новое значение.

**Звенья** (`rigidBodies`): тела — рама {O, B, B2}, кривошип {O, M}; шарнир на двух точках одного тела вваривается в него,
иначе даёт два новых тела. links = число тел без рамы. Янсен — 7, четырёхзвенник — 3, цепочка жёстких треугольников — +0.

**Виды** (`cfg.speciation`, по умолчанию вкл.): вид = links. Квоты пересчитываются каждые 50 спариваний (QUOTA_UPDATE_EVERY):
минимум MIN_SPECIES = 10 мест каждому виду с links > 1 (но не больше половины пула на все минимумы), остаток —
пропорционально (лучшая оценка вида − 1). Рождение: вид ∝ квоте, турнир из 3 внутри вида (из 1–2 ног — сколько есть).
Смерть: вид с наибольшим (размер − квота), худшая из 3 случайных ног вида. Без видов — обычный турнир по всему пулу.

**Оценка** — полный оборот, `STEPS = 120` положений (каждые 3°). Опора — самый длинный непрерывный участок,
где стопа в пределах 1 см от минимума (с переходом через 0°); перенос — остальное.
- нет стопы → 0; не проворачивается → доля оборота, где собирается (0..1);
- нарушает правила → 1: шарнир (кроме стопы) ниже земли + 2 см или стопа выше оси кривошипа (y > 0);
- иначе 1 + скорость × опора × ровность × просвет × подъём × материал:
  - скорость = шаг / доля на земле (см за оборот): столько проходит зверь, если ноги сменяют друг друга;
  - опора = min(1, (доля × LEGS / MIN_FEET)²), LEGS = 6, MIN_FEET = 2. Квадрат нужен: при линейном множителе выигрыш
    в скорости (1/доля) ровно компенсировал бы штраф;
  - ровность = 1 − std/|mean| шагов стопы по x на опоре;
  - просвет = min(1, h / CLEARANCE), CLEARANCE = 10 см; h — минимальная высота стопы, когда она идёт против шага над зоной опоры
    без 15 % по краям (CLEARANCE_MARGIN). Точки, где стопа движется по ходу шага (подход, отрыв), не считаются;
  - подъём = min(1, подъём / (высота ноги / 3)), высота ноги — от оси кривошипа до земли;
  - материал = min(1, (480 / Σ(ra + rb) используемых шарниров)⁴).
- Доп. правила (`FITNESS_OPTIONS`, `setFitnessOptions` — вызывается в конструкторе `Evolution`, пересчитывает `JANSEN_SCORE`):
  множитель 1 − w·(1 − q). height: q = `lowestJoint` (самая низкая используемая точка, кроме стопы, над землёй) / высота ноги;
  angle: q = min(1, худший |sin| угла между стержнями шарнира за оборот / sin 30°) (`worstBarAngle`, `GOOD_ANGLE`);
  compact: q = min(1, `JANSEN_AREA` / `sweptArea`), площадь — габарит всех используемых точек за оборот.
  У Янсена худший угол 8,6°, нижняя точка 27,2 см из 91,8.
- Классы: не работает / нарушает правила / крутится, но не шагает (оценка < 2) / шагает / шагает лучше Янсена.

## Важные решения и грабли

- **Лазейка с размером.** Без ограничения материала эволюция «обгоняла» Янсена за 150 поколений, просто увеличивая длины до предела.
  Отсюда бюджет материала 480 см (сумма b..k у Янсена — 479,4) и фиксированный кривошип. Это ключевой учебный пример: оптимизируется то, что измеряем.
- `STEPS` снижен с 360 до 120 ради скорости (~3,4 тыс. спариваний/с в Node). Оценка Янсена почти не изменилась (22,34 → 22,47).
- **Лазейка «качалка».** В свободном режиме эволюция нашла ногу из одного шарнира на кривошипе и раме: стопа качается по дуге
  и касается земли в обе стороны, то есть тащит тело назад. Закрыто требованием нести стопу над землёй (сейчас — «просвет над шагом»).
- **Лазейка «цеп».** При оценке по скорости стопа на длинном треугольнике улетала выше корпуса по огромной дуге,
  держала опору ровно 1/6 оборота (минимум для 6 ног), а неограниченный бонус за подъём добавлял очков (подъём до 180 см).
  Закрыто: стопа не выше корпуса, бонус за подъём только до трети высоты ноги, на земле всегда 2 ноги.
- **Лазейка «шарканье у земли».** Множитель «доля переноса выше 3 см, без первых и последних 10 %» эволюция обошла:
  стопа шла назад в 3–4 см над землёй или волочилась по земле в последних 20 % переноса. Заменён на «просвет над шагом».
- **Рост сложности — история попыток** (подробно в README, «Как мы к этому пришли»): стартовый пул-цепочка — помог;
  виды без квот — хуже (мелкие виды замирали, пул стекал в простой вид); «нарастить стопу» жёстким треугольником —
  раздувание (четырёхзвенник + цепочка мелких треугольников, вид считался по шарнирам); «нарастить» коротким звеном
  к другому телу — нога рвётся (расстояние до чужого тела меняется на десятки см). Итог: виды по звеньям с квотами, без «нарастить».
- **История оценки.** Сначала было «шаг × доля на земле × …», потом «шаг не меньше, чем у Янсена, + короткий перенос»,
  теперь — скорость (решение пользователя: главное — скорость, не шаркать, ноги поднимать выше).
- Разброс между seed огромный (в одном режиме от 55 до 118). Сравнивать варианты кода — минимум по 6 seed, не по одному-двум.
- Ветвь шарнира фиксирована знаком: через «мёртвую точку» механизм в модели не перескакивает, хотя реальный мог бы.
- В скрытой вкладке `requestAnimationFrame` стоит, и эволюция вместе с ним.

- «Сброс» сохраняет seed, поэтому стартовый пул тот же самый (это сделано ради воспроизводимости). Другой старт даёт кнопка «🎲 Новый seed».
  Seed виден в строке статистики.

## Идеи на перспективу

- Виды сделаны в простой форме (вид = число звеньев, квоты по лучшей ноге). Дальше по NEAT: вид по топологической
  «дистанции» между геномами, квоты по средней приспособленности (fitness sharing), защита нового вида N поколений.
- Мутация, которая добавляет звено, почти не меняя путь стопы (короткое звено не годится, см. грабли) — например,
  вставка диады в середину существующего стержня с подбором длин так, чтобы в начальном положении всё совпадало.
- **Целый зверь в оценке**: показ уже есть (`drawWalker`); дальше — оценивать по ровности хода корпуса (без подпрыгиваний)
  и по реальной смене опоры ног, а не по одной ноге.
- Многокритериальная оптимизация (фронт Парето: шаг / подъём / материал) вместо произведения множителей.
- Динамика: силы в стержнях, крутящий момент на кривошипе, КПД — для реального привода от ветра или мотора.
- Экспорт деталей в SVG/DXF с отверстиями под оси для лазерной резки или печати картонного макета в масштабе.
- Проверка «мёртвых точек» (почти касательные окружности) как штраф: в реальности там нога заклинивает или прыгает.
- Web Worker для фоновых вычислений.
- Обобщить на другие механизмы: захват, механизм Чебышёва для прямолинейного движения, привод дворника.
