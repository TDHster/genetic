# watch — эволюция часов («Слепой часовщик»)

Учебный проект: генетический алгоритм собирает часы из случайной кучи деталей.
Повтор видео «Evolution IS a Blind Watchmaker» (https://www.youtube.com/watch?v=mcAq9bmCeR0, файл видео лежит в этой папке,
ключевые кадры — `docs/frames/video-key-frames.png`). Код автора недоступен: модель восстановлена по тексту в видео.

**Главная цель — понятность для обучения**, а не скорость. Каждая часть системы — отдельный файл с подробными комментариями.

## Запуск и проверка

- Браузер: открыть `index.html` (работает с `file://`, без сервера и интернета).
- Без браузера: `node tools/headless.js [поколений] [пул] [seed]` — грузит те же `js/*.js` через `vm`, результаты совпадают с браузером.
- Эталон для регрессии: `node tools/headless.js 450 2000 1` — маятники до ~270 поколения, к ~425 три стрелки 60 / 3600 / 86400 с.
  В браузере автостоп (0,0001 %) срабатывает на поколении 405,4. Если поведение сильно изменилось, значит, поменялась модель.

## Архитектура

Обычные `<script>` в фиксированном порядке, глобальные функции. Без модулей, сборки и зависимостей: иначе не будет работать `file://`.

| Файл | Роль |
|---|---|
| `js/rng.js` | Генератор mulberry32 с seed. Один seed — одинаковый прогон |
| `js/genome.js` | Детали, 79 точек крепления, матрица связей (3081 пара), `randomGenome`, `crossover`, `mutate` |
| `js/mechanism.js` | «Физика»: `analyzeClock(genome)` — маятники, спуск, пружина, передача, заклинивание, периоды стрелок, роли связей |
| `js/fitness.js` | `evaluateClock` — класс (0..6) и оценка |
| `js/evolution.js` | Класс `Evolution`: пул, турнир из трёх, история, `stopReason` |
| `js/draw-mechanism.js` | Раскладка и анимация лучших часов (canvas) |
| `js/draw-charts.js` | График состава пула, матрица генома с ролями связей |
| `js/app.js` | UI: кнопки, цикл `requestAnimationFrame` (~25 мс эволюции на кадр), панели |

Эволюция ничего не знает про часы. Вся предметная логика — в `mechanism.js` и `fitness.js`.

## Логика модели

**Геном**: отсортированный список индексов включённых пар (разреженная матрица) + `teeth[30]` (4..maxTeeth) + `lengths[7]` (0,01..100 м, лог-равномерно).
Скрещивание — поклеточное (как в видео), мутация одна на потомка: −связь 30 %, +связь 30 %, зубья 25 %, длина 15 %.

**Механизм** (`mechanism.js`, правила в шапке файла):
1. Маятник: стрелка одним концом на корпусе, другим держит шестерню. Стержень и груз больше ни к чему не прикреплены (кроме оси храповика). T = 2π√(L/g).
2. Спуск: ось храповика на стержне маятника, зубья храповика держат зубья ровно одной шестерни — спускового колеса. Оборот колеса = зубья × T.
3. Пружина на шестерне (ось или зубья) её приводит. Корпус подразумевается.
4. Передача: зубья–зубья → ω₂ = −ω₁·z₁/z₂; ось–ось, ось–стрелка, стрелка–стрелка → одна скорость. Обход в ширину, противоречие или блокировка → вся группа заклинена.
5. Группа со спусковым колесом тикает, если в ней есть пружина и нет клина. Период стрелки = период колеса / |относительная скорость|.

**Оценка**: 0 ничего, 1 маятник, 2 прото-часы, 3 + Σ качество для часов со стрелками.
Качество = 1/(1 + 10·|ln(P/цель)|), стрелки сопоставляются с целями жадно, без повторов. Цели по умолчанию 60, 3600, 86400.

**Эволюция**: steady-state. Три случайных, худший умирает, потомок двух лучших занимает его место. Поколение = размер пула спариваний.
Автостоп: точность стрелок, застой, предел поколений. После автостопа «Старт» продолжает без автостопа до «Сброс».

## Важные решения и грабли

- **Пружина без крепления к корпусу.** При строгом правиле «один конец на корпусе, другой на оси» за 300+ поколений часы не появлялись:
  слишком много нейтральных шагов подряд. Ослаблено как в видео (корпус не рисуется).
- Роли связей (`pendulum/escapement/spring/train/jam`, остальное — нейтральные) считаются в `analyzeClock` и нужны только для UI.
- Сравнение периодов на равенство — относительный допуск 1e-9.
- В скрытой вкладке `requestAnimationFrame` стоит, и эволюция вместе с ним.
- Ошибки меньше 1e-6 % показываются как «≈ 0» с точным значением рядом: ровно нуля не бывает, длина маятника — вещественная.

- «Сброс» сохраняет seed, поэтому стартовый пул тот же самый (это сделано ради воспроизводимости). Другой старт даёт кнопка «🎲 Новый seed».
  Seed виден в строке статистики.

## Идеи на перспективу

- Вынести эволюцию в Web Worker (через Blob, чтобы работал `file://`), чтобы считалось в фоне и быстрее.
- Строгий режим пружины (крепление к корпусу) переключателем — показать, как правило модели меняет время до прорыва.
- График «родословной»: от каких предков произошли лучшие часы, когда появилась каждая ключевая связь.
- Отмечать на графике моменты рождения первых прото-часов и часов.
- Больше физики: трение, момент пружины, заводка, вес стрелок; энергозатраты как часть оценки.
- Экспорт механизма в чертёж (SVG с осями и межцентровыми расстояниями) или в CAD.
- Сравнение стратегий отбора: турнир из 3 против отсечения (как в первых видео автора), разные размеры пула.
