# wing — эволюция профиля крыла

Учебный проект: генетический алгоритм ищет сечение крыла (профиль) с наибольшим качеством L/D при Re 10⁶ с запасом до срыва.
Поиск в 2D (панельный метод + пограничный слой, как XFOIL), показ — 3D-аэродинамическая труба на three.js.
Тот же алгоритм, что в соседних проектах; устройство (воркеры, пачки, 3D-модуль) — по образцу `../vawt`. Подробности для людей — в README.md.

**Главная цель — понятность для обучения.** Каждая часть системы — отдельный файл с комментариями.

## Запуск и проверка

- Браузер: только через http-сервер (общий, порт 8765, см. корневой CLAUDE.md): http://localhost:8765/wing/.
  С `file://` эволюция идёт в основном потоке, вместо 3D — подсказка про сервер.
- Без браузера: `node tools/headless.js [поколений] [пул] [seed] [Re] [tMin] [cmMin|none] [circle|brick|lumps]` (`vm.runInThisContext`);
  `node tools/headless.js polar 4412 1e6` — поляра NACA для проверки модели.
  Одна оценка ~12 мс (Node, M1), ~84 спаривания/с в одном процессе; в браузере 8 воркеров — ~560 профилей/с.
- Эталоны (`node tools/headless.js 200 100 <seed>`, старт с круга, Re 10⁶, t ≥ 12 %, Cm ≥ −0,1 — как на странице по умолчанию):
  NACA 4412 **101,20** (L/D 101,2 при 5°, Cl 1,003, Cd 0,00991, Cm −0,096); seed 1–3: **131,60 / 127,24 / 132,00**
  (старт 0,04 — всё срывается; на 100-м поколении 119,67 / 101,70 / 100,75).
  `200 100 1 1e6 0.12 none` → 131,45; `… 0.12 0` → 111,57 (эталон NACA 0012: 67,90); `… 0.08` → 145,29 (эталон NACA 4408: 105,52);
  `150 100 1 1e6 0.12 -0.1 brick` → 138,55 (seed 2: 135,73); `100 100 1 1e6 0.12 -0.1 lumps` → 138,14.
  Если цифры сильно изменились, значит, поменялась модель, оценка или последовательность вызовов rng.
- Поляры NACA (Re 10⁶): 0012 — Cd 0,0073 при 0°, Cl 0,434 при 4°; 2412 — Cl 0,229 и Cm −0,048 при 0°, L/D max ~81 при 6°;
  4412 — L/D max 101 при 5°. Невязкий Cl 0012 при 5° = 0,602, Cm 2412 = −0,053 (теория −0,053).
- Проверка в браузере без GUI: headless Chrome + CDP через встроенный в Node WebSocket (скрипт держать в scratchpad, не в проекте).
  Головной Chrome рисует WebGL через `--use-angle=swiftshader --enable-unsafe-swiftshader`.

## Архитектура

Обычные `<script>` в фиксированном порядке, глобальные функции; только `js/view3d.js` — ES-модуль (`window.View3D` + событие `view3d-ready`).
Имена функций глобальные на все скрипты: `draw2d.js` рисует геном через `drawGenome2d`, потому что `drawGenome` есть в `app.js`.

## Логика модели

- Единицы: хорда 1, скорость потока 1, вязкость 1/Re. Нормаль панели наружу = поворот касательной на +90°; обход по часовой,
  тело справа. Вихрь по часовой (+γ) = скорость источника, повёрнутая на −90°. Кутта: Vt(первой панели) + Vt(последней) = 0.
- Cm относительно 1/4 хорды, плюс — нос вверх. Cl по интегралу давления (совпадает с Кутта — Жуковским в пределах 1 %).
- Связка всегда стартует с нуля на каждом угле (без «тёплого старта» с соседнего угла): иначе результат зависит от пути,
  NACA 0012 переставал быть симметричным, а ползунок на странице не совпадал с полярой.
- «Без отрыва» = точка отрыва на обеих сторонах не раньше 90 % хорды (`AERO.attachedTo`) **и** след не шире 0,04 хорды
  (`AERO.attachedWake`; у NACA срыв как раз при ~0,04). След = расстояние поперёк потока между точками отрыва (или хвостом);
  донное сопротивление `AERO.baseDrag` 0,5 × (след − 0,01). Тело, которое срывается на всех углах, получает оценку
  0,5 × 0,04 / (самый узкий след): у круга ~0,04 — это градиент «сначала стань обтекаемым». За отрывом выдув ограничен 0,08,
  после отрыва в методе Хеда H заморожен на 2,4, cf = 0.
- Оценка: см. шапку `fitness.js`. Запас 3°, штраф за толщину (t/tMin)⁴, штраф за Cm линейный на 0,05; по умолчанию `SETUP.cmMin` −0,1
  (пользователь выбрал: без ограничения эволюция уходит в кривизну 9 %, которую модель, вероятно, переоценивает). Нет рабочего угла —
  0,1 × лучшее L/D без отрыва (чтобы в стартовом пуле был градиент).
- Труба: модель хордой 40 см, размах 1 м, скорость = Re·ν/хорда (37,5 м/с при 10⁶). Дым считается в тех же единицах;
  клубы выпускаются каждые 0,35 хорды/V, линии фронта — каждый третий выпуск, только в ближней плоскости.

## Важные решения и грабли

- **Неустойчивость связки.** Прямая связка «слой ↔ поток» неустойчива у отрыва; 4 прохода с релаксацией 0,6 сходятся до ±0,005 по Cl
  на безотрывных углах — этого хватает. Больше проходов не улучшает.
- **Переход раньше, чем в XFOIL.** Почти всегда через ламинарный отрыв (λ < −0,09), а не по Мишелю; поэтому Cd ~ на 25–35 % выше XFOIL.
- **Сильная кривизна.** Без ограничения на момент эволюция уходит в профили с кривизной 7–9 % и Cm −0,17…−0,24 (класс Selig S1223).
  Вероятно, модель их переоценивает: нет толщины следа в связке, срыв предсказывается только по отрыву у кромки.
  Ограничение «Cm ≥ −0,1» или «≥ 0» даёт более привычные формы (летающее крыло: кривизна ~5 % в 25 %, S-образный хвост, L/D ~113).
- **Стартовый пул грубый нарочно** (`randomAirfoil`): по умолчанию круг (пользователь просил «из кирпича или круга»), все старты
  строго симметричные. История: «толстота + кривизна + шум» давала старт ~122 > эталона; бугристые симметричные профили — ~79,
  но с готовым носком и кромкой. Чтобы старт мог быть кругом/кирпичом, в геном добавлены показатели n1, n2.
- **Круг и кирпич ломали модель — три дыры, все закрыты:** (1) Сквайр — Янг брался в последней точке, а на тупой корме скорость
  там падает до нуля → Cd = 0, L/D ~10¹⁸ (эволюция из кирпича нашла это сразу); теперь максимум по стороне. (2) Без донного
  сопротивления круг «не срывался» (отрыв на 0,95 хорды) и кирпич обгонял эталон. (3) Панели по x: на задней стенке кирпича
  одна панель, отрыв на углу не виден → теперь панели по длине дуги. NACA-цифры от этого почти не изменились (4412: 99,9 → 101,2).
- **Лазейка «клин»:** при n1 до 1 эволюция из круга делает острый носок (ламинарный отрыв у носка модель считает просто
  переходом). Поэтому `WEIGHTS.n1` ≤ 0,6. Кирпич сохраняет плоский торец носка (n1 ≈ 0,2) — тоже некоторая лазейка, задокументировано в README.
- Нос упирается в предел `WEIGHTS.nose` (0,05) снизу: эволюции выгоден острый нижний носок.
- 3D: стрелки сил рисуются поверх всего (`depthTest: false`), иначе их прячет крыло. Без торцов крыло — открытая труба,
  сквозь которую видно фон; вентилятор в диффузоре убран по просьбе пользователя.
