# Генетические алгоритмы проектируют физические механизмы

Пять учебных проектов. `watch` и `teo-leg` работают в браузере без сервера: открыть `index.html` в папке проекта.
`builder`, `coast` и `vawt` нужен локальный сервер (Web Workers, ES-модули и wasm-физика не работают с `file://`):
`python3 -m http.server 8765` в этой папке, затем http://localhost:8765/builder/, http://localhost:8765/coast/ или http://localhost:8765/vawt/.

| Папка | Что эволюционирует | Что меняет эволюция |
|---|---|---|
| [watch/](watch/README.md) | Часы из случайной кучи деталей (по видео «Evolution IS a Blind Watchmaker») | Связи между деталями (топология) + числа зубьев и длины |
| [teo-leg/](teo-leg/README.md) | Шагающая нога на кривошипе, критерий — скорость; эталон — нога Тео Янсена | Свободный режим: всё (шарниры, связи, длины, стопа); режим Янсена: только длины |
| [builder/](builder/README.md) | Самая высокая постройка из неровных камней, которая выдерживает наклон гравитации | План каменщика: какой камень, где, какой гранью вниз, поворот, наклон, порядок |
| [coast/](coast/README.md) | Защита набережной от столетнего шторма: без перехлёста через стенку, прочно и дёшево; симуляция волн | Сооружения перед набережной: сколько, где, угол, длина, ширина, высота гребня, из каких блоков |
| [vawt/](vawt/README.md) | Ротор ветряка с вертикальной осью (Дарье): энергия за год, самозапуск, без рывков; модель трубок тока | Число лопастей, форма по высоте (прямая, «взбивалка»), хорда, закрутка спиралью, установочный угол, толщина профиля |

Общее у всех: один и тот же простой алгоритм (турнир из трёх, худший умирает, потомок с одной мутацией).
Различается только «модель мира» (что получается из генома) и оценка (что считается хорошим).

## Публикация (genetic.tdhster.workers.dev)

Сайт — Cloudflare Worker `genetic`, только статика ([wrangler.jsonc](wrangler.jsonc)). `./make-site.sh` собирает чистую папку `site/`:
без `tools/`, `CLAUDE.md` и видео, с Cloudflare Web Analytics на каждой странице.

- **Автоматически**: Workers Builds подключён к git-репозиторию. Пуш в `main` → Cloudflare сам запускает
  `./make-site.sh` и `npx wrangler deploy`.
- **Вручную**: `./make-site.sh && npx wrangler deploy` (один раз `npx wrangler login`).
