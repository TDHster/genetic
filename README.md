# Генетические алгоритмы проектируют физические механизмы

Десять учебных проектов. `watch`, `teo-leg`, `roof`, `roads` и `bridge` работают в браузере без сервера: открыть `index.html` в папке проекта.
`builder`, `coast`, `vawt`, `wing` и `propeller` нужен локальный сервер (Web Workers, ES-модули и wasm-физика не работают с `file://`):
`python3 -m http.server 8765` в этой папке, затем http://localhost:8765/builder/, http://localhost:8765/coast/, http://localhost:8765/vawt/, http://localhost:8765/wing/ или http://localhost:8765/propeller/.

| Папка | Что эволюционирует | Что меняет эволюция |
|---|---|---|
| [watch/](watch/README.md) | Часы из случайной кучи деталей (по видео «Evolution IS a Blind Watchmaker») | Связи между деталями (топология) + числа зубьев и длины |
| [teo-leg/](teo-leg/README.md) | Шагающая нога на кривошипе, критерий — скорость; эталон — нога Тео Янсена | Свободный режим: всё (шарниры, связи, длины, стопа); режим Янсена: только длины |
| [builder/](builder/README.md) | Самая высокая постройка из неровных камней, которая выдерживает наклон гравитации | План каменщика: какой камень, где, какой гранью вниз, поворот, наклон, порядок |
| [coast/](coast/README.md) | Защита набережной от столетнего шторма: без перехлёста через стенку, прочно и дёшево; симуляция волн | Сооружения перед набережной: сколько, где, угол, длина, ширина, высота гребня, из каких блоков |
| [vawt/](vawt/README.md) | Ротор ветряка с вертикальной осью (Дарье): энергия за год, самозапуск, без рывков; модель трубок тока | Число лопастей, форма по высоте (прямая, «взбивалка»), хорда, закрутка спиралью, установочный угол, толщина профиля |
| [roof/](roof/README.md) | Крыша, с которой капля скатывается быстрее всего (брахистохрона → циклоида); режим «дождь по всей крыше» | Высоты точек излома ломаной ската |
| [roads/](roads/README.md) | Сеть дорог между городами: компромисс «дёшево построить — быстро ездить» (ползунок), самая короткая сеть (задача Штейнера); эталоны — остовное дерево и точные ответы для треугольника, квадрата, шестиугольника | Дороги (какие пары узлов соединить) и развилки в поле; второй режим — только развилки, дороги строит алгоритм |
| [bridge/](bridge/README.md) | Мост через случайную долину: самая лёгкая ферма, которая держит грузовик (расчёт методом жёсткостей, разрыв, выпучивание, прогиб); эталон — ферма Уоррена | Узлы и стержни фермы (топология), сечения труб |
| [wing/](wing/README.md) | Профиль крыла планера: наибольшее качество L/D с запасом до срыва (панельный метод + пограничный слой, как XFOIL), 3D-аэродинамическая труба с дымом; эталон — NACA 4412 | 12 весов CST (форма поверхностей) + 2 показателя «типа тела»: старт с круга или кирпича |
| [propeller/](propeller/README.md) | Винт подводной лодки: тише всего на патруле у поверхности (тоны лопастей от следа стабилизаторов, сплошной шум, кавитация), не медленнее эталона на полном ходу; модель BEM, 3D-корма с пузырями кавитации; эталон — 7-лопастной саблевидный | Число лопастей, диаметр, шаг и ширина по радиусу, изгиб и толщина профиля, откос (сабля), насадка (pump-jet) со статором |

Общее у всех: один и тот же простой алгоритм (турнир из трёх, худший умирает, потомок с одной мутацией).
Различается только «модель мира» (что получается из генома) и оценка (что считается хорошим).

## Публикация (genetic.tdhster.workers.dev)

Сайт — Cloudflare Worker `genetic`, только статика ([wrangler.jsonc](wrangler.jsonc)). `./make-site.sh` собирает чистую папку `site/`:
без `tools/`, `CLAUDE.md` и видео, с Cloudflare Web Analytics на каждой странице.

- **Автоматически**: Workers Builds подключён к git-репозиторию. Пуш в `main` → Cloudflare сам запускает
  `./make-site.sh` и `npx wrangler deploy`.
- **Вручную**: `./make-site.sh && npx wrangler deploy` (один раз `npx wrangler login`).
